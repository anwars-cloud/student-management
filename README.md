Student Management System

A simple and responsive Student Management System built using HTML, CSS, and JavaScript.

Project Overview

This project allows users to add and manage student records through a clean and user-friendly interface. It was created as part of a Git & GitHub practical assignment.

Features

- Add student records
- Enter student name, roll number, email, and course
- Prevent duplicate roll numbers
- Delete student records
- Responsive layout for mobile and desktop
- Simple and clean user interface

Technologies Used

- HTML5 – Page structure
- CSS3 – Styling and responsive design
- JavaScript – Form handling and student record management
- Git – Version control
- GitHub – Remote repository and code hosting

Project Structure

student-management/
├── index.html
├── style.css
└── README.md

How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open "index.html" in your web browser.
4. Enter student details and click Add Student.
5. Use the Delete button to remove a record.

Important Note

Student records are stored temporarily in browser memory. They are not saved to a database and will disappear when the page is refreshed.
